# Estrutura pública do case study

Este repositório foi organizado para apresentar o Sistema LJV sem expor o código operacional, dados da loja, credenciais ou rotinas internas.

```text
.
├── docs/            Documentação pública do case study
├── screenshots/     Interface atual e registros de evolução visual
├── README.md         Visão geral do produto
└── .gitignore        Proteção contra arquivos locais e sensíveis
```

## Organização das imagens

```text
screenshots/
├── atual/       Telas da versão atual do Sistema LJV
└── evolucao/    Registros visuais de versões anteriores
```

O repositório público não inclui o código-fonte completo, banco de dados, backups, variáveis de ambiente ou configurações de produção.
